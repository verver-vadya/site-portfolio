# site-portfolio

Сайт-портфолио verver. Сам сайт тоже работа в портфолио: он должен впечатлять видом и движением, поэтому главная сделана как 3D-сцена. Страницы:

- главная: огромная надпись verver стоит на тёмной воде и отражается в ней; курсор и пальцы оставляют круги. При прокрутке буквы уходят под воду, а из воды поднимается кольцо со скриншотами работ. Кольцо крутится мышкой, пальцем и кнопками ← →, по клику панель разворачивается в первый экран страницы работы. Дальше сетка работ и призыв оставить заявку;
- «Работы» (`/works/`): сетка работ с переключателем «Компьютер / Телефон»;
- «Цены» (`/prices/`): тарифы, гарантия, условия и вопросы;
- «Обо мне» (`/about/`) и «Связаться» (`/contact/`, форма заявки);
- у каждой работы своя страница: задача, решение, скриншоты, ссылка на живой сайт; плюс политика конфиденциальности и страница 404.

Превью: https://verver-vadya.github.io/site-portfolio/

Стек: [Next.js](https://nextjs.org) со статической сборкой (`output: "export"`, сервер не нужен), React, сцена на [three.js](https://threejs.org) через [React Three Fiber](https://r3f.docs.pmnd.rs), плавная прокрутка [Lenis](https://lenis.darkroom.engineering). Шрифты Unbounded и Onest подключаются через `next/font` и лежат вместе с сайтом. Бэкенда нет, заявки уходят в Formspree.

## Добавить работу

Одна работа = одна папка в `content/cases/<папка>/`: файл `index.md` и скриншоты рядом. Кольцо, сетка, страница работы и карта сайта собираются из этих папок сами.

1. Снять скриншоты и создать заготовку (нужен Node.js 20+ и Chromium для Playwright):

   ```bash
   npm ci
   npx playwright install chromium   # один раз
   npm run case -- kare https://verver-vadya.github.io/site-kare/
   ```

   Скрипт снимает по три экрана на компьютере (1440×900) и телефоне (390×844) и, если работы ещё нет, создаёт `index.md` с пометками `[ЗАПОЛНИТЬ: …]` (автопроверка не пропустит их на сайт). Повторный запуск обновляет только скриншоты.

2. Заполнить в `index.md` название, нишу, город, одну фразу о сайте, подпись для каталога (`tagline`, одна строка с лёгкой иронией), срок (`term`, например «Две недели») и тексты «Задача» и «Решение». Поле `status: concept` ставит бирку «Концепт» (учебная работа), `client` — настоящий заказ. `order` задаёт порядок, `live: false` прячет ссылку, пока превью нет.

3. Открыть pull request. После слияния работа появится на сайте.

Проще всего попросить Claude: «добавь site-X в портфолио». Он сделает эти три шага сам.

## Запуск локально

```bash
npm ci
npm run dev                     # http://localhost:3000/site-portfolio/
BASE_PATH=/ npm run build       # сборка в dist/ с корнем "/"
npm run preview                 # посмотреть сборку: http://localhost:4321/
```

Перед `dev` и `build` скрипт `scripts/images.mjs` делает из скриншотов WebP разных ширин в `public/img/` (папка не хранится в git). Адрес сайта задаёт `BASE_PATH`: без него сборка рассчитана на `/site-portfolio/`, как на GitHub Pages.

3D-сцену можно включить и там, где сайт её обычно не показывает (слабая графика, автотесты): `?scene=force` в адресе главной. Для записи ровного видео на медленной машине есть `?scene=record`: сцена стоит на месте, а время двигает скрипт через `window.__sceneAdvance(секунды)`, после каждого шага снимается кадр.

## Где что

- `app/` — страницы: `page.tsx` главная, `works/`, `prices/`, `about/`, `contact/`, `privacy/`, `cases/[slug]/` страница работы, `not-found.tsx` 404; `layout.tsx` общий каркас (шапка, сцена, подвал, заставка, движение); `globals.css` токены: цвета обеих тем, шрифты, отступы, движение.
- `components/home/` — первый экран главной (`Hero`: заголовок и надпись verver, она же запасной вариант без 3D) и сцена кольца (`Stage`: подпись работы, кнопки ← → и «Открыть работу»).
- `components/scene/` — 3D-сцена: `SceneRoot` решает, показывать ли её, и грузит отдельным куском только на главной; `World.tsx` надпись, вода, кольцо, камера и раскрытие панели; `materials.ts` шейдеры; `ripples.ts` круги на воде; `word.ts` буквы из логотипа.
- `components/motion/` — `Intro` заставка (две «v» сходятся в ромб, один раз за визит), `Motion` плавная прокрутка, ромб-шторка между страницами, курсор-ромб и проявление блоков при прокрутке.
- `lib/gsap.ts` — GSAP с ScrollTrigger и нашими кривыми (soft, close, hover, quick из setup/motion-examples.md). Импортируй GSAP только отсюда. Шпаргалки GSAP для Claude лежат в `.claude/skills/gsap-*`.
- `components/works/` — сетка работ, карточка, переключатель «Компьютер / Телефон».
- `components/prices/`, `components/about/`, `components/form/` — цены и вопросы, «Обо мне» и фото, форма заявки с проверкой полей.
- `components/Header.tsx`, `Footer.tsx`, `ThemeSwitch.tsx`, `Logo.tsx`, `Cta.tsx` — шапка, подвал, переключатель темы, логотип, «Расскажите о задаче» в конце страниц.
- `lib/site.ts` — имя, ФИО, статус, ИНН, Telegram, почта и номер формы Formspree: отсюда они попадают в «Обо мне», заявку, подвал и политику.
- `lib/cases.ts` — чтение работ из `content/cases/`; `lib/brand.ts` контуры логотипа; `lib/meta.ts` заголовки и превью для мессенджеров.
- `scripts/add-case.mjs` — снимки для новой работы; `scripts/images.mjs` — WebP из скриншотов.

## Как это двигается

- Сцена показывается на компьютерах и телефонах с нормальной графикой. Без WebGL, при слабой графике и при выключенных в системе анимациях вместо неё обычная страница: надпись с отражением на CSS и сетка работ, всё работает так же.
- Кольцо: на горизонтальном экране в нём экраны компьютера, на вертикальном — экраны телефона. Само делает шаг раз в несколько секунд, пока его не трогают. Быстрое вращение смазывает картинки, панель под курсором выдвигается.
- Между страницами новая страница раскрывается ромбом из точки клика (View Transitions, Chrome, Edge, Safari 18+; в остальных браузерах просто переход). Шапка при этом стоит на месте.
- Курсор на компьютере — маленький ромб: над ссылкой становится контуром, над работой — плашкой «Открыть».
- Плавная прокрутка колесом только на компьютере с мышью; на телефоне и при выключенных анимациях обычная.
- Тема по умолчанию тёмная; внизу каждой страницы переключатель «Тёмная / Светлая / Как в системе», выбор запоминается в браузере. Сцена берёт цвета из той же темы.

## Заявки

Форма отправляет заявку в [Formspree](https://formspree.io), письмо приходит на почту verver.company@mail.ru. Форма подключена (номер в `lib/site.ts`, поле `formspree`). Подключить заново, например для другой почты:

1. Зарегистрироваться на formspree.io, создать форму, указать почту для заявок.
2. Скопировать номер формы из адреса вида `https://formspree.io/f/abcdwxyz` и поставить его в поле `formspree` в `lib/site.ts`.
3. Отправить пробную заявку и подтвердить почту в письме от Formspree.

Formspree хранит данные за рубежом; для российской аудитории на запуск лучше свой приёмник в России, например небольшая функция в Яндекс Облаке, которая пересылает заявку в Telegram-бот. Токен бота хранится только в переменных окружения функции, не в коде сайта.

## Автопроверка

В каждом pull request сайт собирается и проверяется (Actions → «Проверка сайта»): битые ссылки, состояния кнопок, мелкие зоны нажатия, ошибки в консоли, ширины от 320 до 2560 px и масштаб Windows 125 % и 150 %, наложения, движение, заглушки. Подробности и чек-лист: `.github/check/check.mjs` и `.github/CHECKLIST.md`. Проверка идёт в браузере без видеокарты, поэтому смотрит страницы без 3D-сцены.

## Публикация

После слияния в `main` сайт сам собирается и выкладывается на GitHub Pages (Actions → «Deploy preview to GitHub Pages»). Чужие шрифты и библиотеки и их лицензии перечислены в `CREDITS.md`.
