# Источник снимков

Скриншоты реальных страниц «Алого» из [успешного CI](https://github.com/verver-vadya/site-aly/actions/runs/40084539272), исходный коммит 80a317218b7e660a0fc19607b777f7026f13087e.

desktop-1 / phone-1 — главная; desktop-2 / phone-2 — каталог; desktop-3 / phone-3 — конструктор. Снимки всей страницы обрезаны до первого экрана: 1280×900 и 375×800. Содержимое интерфейса не дорисовывалось. Исходный артефакт CI содержит полные страницы и дополнительные размеры.

Сливать этот кейс после публикации site-aly и проверки его build-метки. Ссылка на превью включена в данных кейса; без публикации «Алого» она ещё не работает.
