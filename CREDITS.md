# Чужое в этом сайте и лицензии

## Шрифты

- **Unbounded** — NamelessDesign, лицензия SIL Open Font License 1.1. Заголовки, цены, логотип verver (контуры букв в `lib/brand.ts` сделаны из этого шрифта).
- **Onest** — Dmitri Voloshin (CSTM Fonts), лицензия SIL Open Font License 1.1. Основной текст.

Оба шрифта подключаются через `next/font/google`: при сборке файлы скачиваются и лежат вместе с сайтом, браузер посетителя к Google не обращается.

## Библиотеки

- **Next.js**, **React** — лицензия MIT.
- **three.js** — лицензия MIT.
- **@react-three/fiber** — лицензия MIT.
- **DialKit** (Josh Puckett) — панель подбора движения кольца по адресу с ?dial, лицензия MIT.
- **Bloom** (`bloom-menu`, Josh Puckett) — меню на телефоне, лицензия MIT; тянет **framer-motion / motion** (MIT).
- **Pasito** (Josh Puckett) — точки работ под кольцом, лицензия MIT.
- **Lenis** (плавная прокрутка) — лицензия MIT.
- **marked** (тексты кейсов из Markdown) — лицензия MIT.
- **yaml** — лицензия ISC.
